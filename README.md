# Система управления затратами горнодобывающего предприятия

> MVP для финала НТО по профилю «Автоматизация бизнес-процессов»

## 📋 Описание

Система управления затратами для участка добычи и транспортировки руды. Реализует контур **план → факт → отклонение → отчёт** в среде 1С:Предприятие 8.3 (учебная версия).

### Целевые бизнес-метрики

| Метрика | Целевое значение |
|---------|------------------|
| Время закрытия периода | ≤ 1 рабочий день (было: 5 дней) |
| Снижение перерасхода по топливу и материалам | 10–15% |
| Доля затрат в единой системе | 100% (без Excel) |

## 🚀 Быстрый старт

### 1. Развёртывание среды

1. Установить **1С:Предприятие 8.3** (учебная версия).
2. Создать пустую файловую базу.

### 2. Создание объектов

| Фаза | Задача | Результат |
|------|--------|-----------|
| Phase 1 | T-001…T-004 | Справочники + демо-данные |
| Phase 2 | T-101…T-107 | Регистр + документы + движения |
| Phase 3 | T-201…T-205 | Отчёты СКД + дашборд + роли |

### 3. Демо-сценарий

1. Заполнить справочники (участок, 4 статьи, нормы).
2. Провести документ «План затрат» (месяц, статья, сумма).
3. Провести документ «Факт затрат» (дата, статья, сумма).
4. Провести документ «Выпуск продукции» (тонны).
5. Сформировать отчёт «План-факт» — увидеть отклонения.
6. Открыть дашборд — увидеть топ-3 статьи с перерасходом.

## 🔒 Безопасность

Threat Model: **STRIDE** (baseline).

| ID | Угроза | Уровень | Контроль |
|----|--------|--------|----------|
| TM-01 | Искажение суммы факта | High | Валидация суммы > 0 |
| TM-02 | Отрицание проведения | Medium | Журнал регистрации 1С |
| TM-03 | Превышение прав | Medium | Разграничение ролей |

## 📊 Non-Functional Requirements

| ID | Требование | Метрика |
|----|-----------|---------|
| NFR-001 | Производительность отчёта | ≤ 3 сек при 10 000 записей |
| NFR-002 | Атомарность проведения | При ошибке — полный откат |
| NFR-003 | Аудит | Журнал регистрации 1С |
| NFR-004 | UX ввода | ≤ 4 действия на строку факта |
| NFR-005 | Совместимость | Учебная версия 1С |
