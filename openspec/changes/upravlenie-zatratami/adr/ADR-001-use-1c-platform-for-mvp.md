# ADR-001: Использование 1С:Предприятие 8.3 (учебная версия) как платформы MVP

## Статус
Accepted

## Контекст
Финал НТО по профилю «Автоматизация бизнес-процессов» ориентирован на 1С: в этапе I есть образовательный курс по 1С, наставникам рекомендована программа «Лёгкий старт» от УЦ №1 Фирмы 1С. Команда из 2 человек, срок — окно финала. Нужен работающий учётный контур (план/факт/выпуск, регистр, отчёт) без интеграций. Ограничение из constraints: `1С:Предприятие 8.3 (учебная версия)`.

## Решение
Реализовать MVP на 1С:Предприятие 8.3 (учебная версия) с использованием стандартных механизмов: справочники, документы, регистр накопления, отчёты СКД, встроенные роли. Файловая база, без клиент-серверного варианта.

Обоснование: соответствие ожиданиям профиля, быстрая разработка учётного контура, доступность учебной версии, наличие готовых механизмов валидации и аудита (журнал регистрации), что закрывает NFR-SEC-001 и NFR-SEC-002 без собственной разработки.

## Последствия
**Плюсы:**
- Соответствие профилю олимпиады и ожиданиям жюри.
- Стандартные механизмы валидации, транзакций и аудита «из коробки».
- Быстрый старт: справочники/документы/регистр/СКД.

**Минусы:**
- Требуется время на освоение 1С командой.
- Учебная версия имеет ограничения по объёму данных и многопользовательской работе.

**Риски:**
- Команда незнакома с 1С → **Митигация:** курс «Лёгкий старт», фокус на стандартных механизмах.
- Ограничения учебной версии → **Митигация:** тестовый набор ≤ 10 000 записей (NFR-001), файловая база.

## Альтернативы
| Альтернатива | Отклонена | Причина |
|---|---|---|
| Веб-приложение (Python/Django + PostgreSQL) | Да | Не соответствует профилю НТО (фокус на 1С); больше времени на инфраструктуру |
| Excel + макросы | Да | Не является «системой автоматизации»; нет разграничения ролей и аудита |
| 1С:ERP / 1С:УПП | Да | Избыточно для MVP; учебная версия ограничена; сложность настройки |
