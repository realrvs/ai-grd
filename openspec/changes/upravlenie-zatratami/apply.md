## Feature Flags

| Flag | Default | TTL | Связанный FR | Связанный TM |
|---|---|---|---|---|
| `FF_PLAN_FACT_REPORT` | ON | до защиты | FR-005, FR-006 | — |
| `FF_DASHBOARD` | ON | до защиты | FR-007 | — |
| `FF_STRICT_VALIDATION` | ON | бессрочно | NFR-SEC-001 | TM-01 |
| `FF_AUDIT_JOURNAL` | ON | бессрочно | NFR-SEC-002, NFR-003 | TM-02 |
| `FF_ROLE_SPLIT` | ON | бессрочно | FR-008, NFR-SEC-003 | TM-03 |
| `FF_NORMATIVE_CALC` | ON | до защиты | FR-004 | — |

> **Примечание:** в 1С feature flags реализуются через константы (`Константа.FF_*`) и условия в коде. TTL «до защиты» означает, что флаг может быть отключён для упрощённого демо, если возникнут проблемы; security-флаги (`FF_STRICT_VALIDATION`, `FF_AUDIT_JOURNAL`, `FF_ROLE_SPLIT`) **не отключаются** — они покрывают TM-01…TM-03.

## Canary Deployment

1. **Этап 1 — Администратор.** Включить конфигурацию для пользователя с ролью «Администратор». Проверить: доступ к справочникам и нормам, отсутствие доступа к вводу факта (TC-014, TC-021).
2. **Этап 2 — Руководитель участка (тестовый пользователь).** Включить роль «Руководитель участка» для одного тестового пользователя. Прогнать демо-сценарий: план → факт → отчёт → дашборд (TC-001…TC-013).
3. **Этап 3 — Все пользователи.** После успешных этапов 1–2 включить роли для всех пользователей участка. Прогнать security-тесты (TC-004, TC-017, TC-020) и тесты производительности (TC-015).
4. **Этап 4 — Фиксация.** Снять резервную копию базы (`backup/before-defense.dt`), зафиксировать версию конфигурации.

## Rollback Plan

1. **Откат конфигурации:** восстановить `backup/config-before-mvp.cf` (предыдущая версия конфигурации) через «Загрузить конфигурацию из файла».
2. **Откат данных:** восстановить `backup/before-defense.dt` (резервная копия базы) через «Восстановить базу из файла».
3. **Откат ролей:** снять роли с пользователей, удалить тестовых пользователей (M-004 rollback).
4. **Откат feature flags:** установить `FF_PLAN_FACT_REPORT`, `FF_DASHBOARD`, `FF_NORMATIVE_CALC` в `OFF`; security-флаги оставить `ON`.
5. **Проверка:** прогнать TC-019 (запуск на учебной версии) и TC-011 (формирование отчёта) после откката.
